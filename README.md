# 🎲 The Rolistes Podcast website

👉 Live site: https://rolistespod.com/

Official website of The Rolistes, a London-based podcast for tabletop RPG fans, with 60+ episodes.

## About the project

I designed, built and have maintained this site since 2021. It started as my first React project and is the reason I decided to become a developer.

- **2021:** built with React and Bootstrap
- **2022:** migrated to Next.js for better performance and SEO

## Features

- Episode listing fetched automatically from the podcast RSS feed?
- Other features: episode pages, embedded player, host pages, adjacents news
- Future features: shop section to showcase boardgames created by The Rolistes

Next.js · React · Bootstrap · hosting: GitHub Pages
